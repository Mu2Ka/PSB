## Запуск RAG

```powershell
uv run rag_pipeline.py
```

Вопросы — в списке `questions` функции `demo_basic_rag()` в `rag_pipeline.py`.
Обычные настройки хранятся в `.env`, ключ OpenRouter — в `.env.local` рядом
со скриптом. Оба файла исключены из Git. `.env.example` — шаблон без ключей.
Копирование шаблона в `.env` не меняет секрет из `.env.local`.
Настройки загружаются относительно скрипта, независимо от текущей папки терминала.
Приоритет непустых значений: окружение процесса, затем `.env.local`, затем `.env`.
В новом клоне создайте `.env.local` со строкой `OPENROUTER_API_KEY=ваш_ключ`.
Не публикуйте этот файл.

Локально используются OpenRouter, Nemotron для ответов и text-embedding-3-small
для эмбеддингов. Генерация использует модель `:free`, эмбеддинги тарифицируются
OpenRouter. Если окружение предоставляет все настройки платформы (`LLM_BASE_URL`,
`LLM_API_KEY`, `LLM_MODEL`), режим `RAG_PROVIDER=auto` выбирает платформу.
